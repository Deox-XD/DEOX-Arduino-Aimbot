# Contributing to DEOX

Thank you for your interest in contributing to DEOX! We welcome contributions from the community.

## 🤝 How to Contribute

### Reporting Issues

1. **Check existing issues** - Make sure the issue hasn't been reported already
2. **Use a clear title** - Describe the issue concisely
3. **Provide details**:
   - Your operating system and version
   - Python version
   - Arduino Leonardo board info
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots if applicable

### Submitting Pull Requests

1. **Fork the repository**
2. **Create a feature branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes**:
   - Follow PEP 8 style guidelines for Python code
   - Add comments for complex logic
   - Update documentation if needed
4. **Test thoroughly**:
   - Ensure all existing functionality still works
   - Test your new feature extensively
5. **Commit with clear messages**:
   ```bash
   git commit -m "Add: Brief description of changes"
   ```
6. **Push to your fork**:
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Open a Pull Request** with a detailed description

## 📋 Code Style

### Python
- Follow PEP 8 guidelines
- Use meaningful variable names
- Add docstrings to classes and functions
- Keep functions focused and concise
- Use type hints where applicable

### Arduino
- Use clear, descriptive comments
- Follow standard Arduino naming conventions
- Keep code efficient and optimized

## 🎯 Areas for Contribution

We welcome contributions in these areas:

- **Performance optimizations** - Improve detection speed or accuracy
- **New features** - Additional targeting modes or configurations
- **Documentation** - Improve guides, add tutorials
- **Bug fixes** - Resolve issues from the issue tracker
- **Code quality** - Refactoring, optimization, cleanup
- **Testing** - Add test coverage

## ⚠️ Important Notes

- **Do NOT** submit contributions that:
  - Aim to bypass anti-cheat systems
  - Violate game Terms of Service more severely
  - Include malicious code
  - Compromise user security or privacy

- **Always** ensure your contributions:
  - Maintain the educational purpose of the project
  - Include proper documentation
  - Are tested on your own system
  - Respect the MIT license

## 💬 Questions?

If you have questions about contributing, feel free to:
- Open a discussion on GitHub
- Ask in an existing issue thread
- Review previous contributions for examples

## 🙏 Thank You!

Every contribution, no matter how small, helps improve DEOX for everyone. We appreciate your time and effort!
